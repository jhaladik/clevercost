ICON FILES REQUIRED
===================

You need to create 4 PNG icon files before installing the extension:

1. icon16.png  (16x16 pixels)
2. icon32.png  (32x32 pixels)
3. icon48.png  (48x48 pixels)
4. icon128.png (128x128 pixels)

QUICK OPTIONS:
--------------

Option 1: Use an online icon generator
- Visit: https://favicon.io/favicon-converter/
- Upload a robot emoji or bot image
- Download all sizes
- Rename to match the names above

Option 2: Use Canva (free)
- Go to https://www.canva.com/
- Create custom size designs for each dimension
- Use robot emoji 🤖 or bot graphics
- Download as PNG

Option 3: Simple solid color icons
- Use any image editor
- Create solid purple/blue backgrounds
- Add white "BOT" or robot emoji text
- Export as PNG in required sizes

DESIGN SUGGESTIONS:
-------------------
- Use purple/blue gradient (matches the popup theme)
- Include robot emoji 🤖 or bot symbol
- Keep it simple and recognizable
- Make sure it's visible at 16x16 size

Once created, place all 4 PNG files in this directory (browser-extension/icons/).
